# Veloura Nails Haute Atelier & Nail Tech Business Operating System (OS)

> An all-in-one luxury nail studio web application uniting a client-facing haute atelier with a private Nail Tech Business Operating System designed for master nail artists, salon directors, and boutique studios.

---

## ✦ Key Highlights

- **Bi-Directional Real-Time Synchronicity**: Actions executed in the management portal (design catalog updates, pricing changes, walk-ins, appointment status changes, client reviews) immediately propagate to the public storefront and archival lookbook.
- **Continuous Local Persistence**: Powered by React Context API and `localStorage`, ensuring complete resilience across browser sessions without data loss.
- **React Bits Liquid Glass Display Engine**: Embedded SVG filter primitives (`feTurbulence` with fractal noise and `feDisplacementMap`) simulating optical refraction, dynamic cursor-tracking specular sheens, and gold/champagne prism edge highlights.
- **Security & Access Control**: Dedicated stylist login gateway with credential verification, demo helper, and 256-bit encrypted session badges.
- **Dual Output Receipt Engine**: Instant M-Pesa deposit calculation, printable digital receipts with `@media print` rules, and offline `.txt` receipt download.

## ✦ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/versalylabs/veloura-nail-tech-ms.git

# Enter project directory
cd veloura-nail-tech-ms

# Install dependencies
npm install --legacy-peer-deps

# Start Vite development server
npm run dev
```
